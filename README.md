# Week 2 skincare e-commerce assignment

## Run locally

1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.

## What to understand

- `app/page.js` is the page. The `products` array is the data for the four cards.
- `useState(0)` stores the cart count. `setCartCount` updates it after a button click.
- `app/globals.css` creates the responsive grid: four columns on desktop, two on smaller screens.
- `alt` text on each image improves accessibility.
